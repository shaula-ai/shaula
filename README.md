# Shaula

Shaula is a skill bank and router for small language models.

Install: `pip install shaula-ai`

`shaula` is a namespace package. Components are separate distributions that
install into the same namespace:

| Import | Distribution | Repository |
| --- | --- | --- |
| `shaula.core` | `shaula-ai` | [shaula-ai/shaula](https://github.com/shaula-ai/shaula) |
| `shaula.router` | `shaula-skill-router` | [shaula-ai/Shaula-Skill-Router](https://github.com/shaula-ai/Shaula-Skill-Router) |

## Status

Pre-alpha. This release (0.0.2) contains the namespace layout and a version
helper only. It has no runtime functionality yet.
